# 🌱 Akarfarm.com

Website company profile untuk **Akarfarm** — dibangun dengan HTML, CSS, dan JavaScript.

---

## 📋 Deskripsi

Akarfarm.com adalah website company profile yang menampilkan informasi seputar Akarfarm, mulai dari profil perusahaan, produk unggulan, blog, hingga cara menghubungi.

---

## 🛠️ Teknologi

- **HTML**
- **CSS**
- **JavaScript**

---

## 📁 Struktur Folder

```
akarfarm/
├── assets/               # Gambar, icon, dan aset visual
├── blog/                 # Konten & halaman artikel blog
├── index.html            # Halaman utama
├── about.html            # Halaman tentang kami
├── blog.html             # Halaman daftar blog
├── careers.html          # Halaman karir
├── contact.html          # Halaman kontak
├── melon.html            # Halaman produk melon
├── stroberi.html         # Halaman produk stroberi
├── presskit.html         # Halaman press kit
├── sustain.html          # Halaman sustainability
└── README.md
```

## 🚀 Cara Menjalankan

Tidak perlu instalasi apapun. Cukup:

1. Clone repository ini
   ```bash
   git clone https://github.com/ryanagdii/akarfarm.git
   ```
2. Buka file `index.html` di browser

Atau langsung kunjungi: **[akarfarm.com](https://akarfarm.com)**
